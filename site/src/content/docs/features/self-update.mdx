## How it works

The server serves `GET /api/v1/manifest/daemon?channel=<channel>`. A beta server answers `204 No Content` to any caller that does not ask for `beta`, so a daemon on stable is never offered a beta, and the daemon checks the version's channel again on its side. Older versions are never installed automatically; roll back by pointing the server at an older tag. Both channels pass the same CI gate and every asset is signed the same way.
