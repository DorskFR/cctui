## How it works

The web UI is a SvelteKit single-page app built on a shared UI kit whose themes are CSS custom-property blocks; a theme change is one attribute on the root element. There is no PWA manifest or service worker today, so "install to home screen" is the browser's own bookmark, and there is no command palette.
