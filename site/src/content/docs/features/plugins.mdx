## How it works

A plugin manifest declares its surfaces. The server stores the archive in the blob store, extracts it into memory and serves its static files; each pod reloads when the table changes. The SPA imports pane and page modules at runtime through `PluginPaneHost` and `PluginPageHost`. For development, `CCTUI_PLUGINS_DIR` is a read-only source that `POST /api/v1/plugins/rescan` re-reads without a restart; the local stack mounts `deploy/local/plugins`.

`docs/plugins.md` in the repository is the full manifest and SDK reference.
