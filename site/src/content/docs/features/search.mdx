## How it works

Events are stored in PostgreSQL and indexed with its full-text search; the query language (`cctui-query`) compiles facets into the same SQL, scoped to what the user owns or was shared. Context items are server-side records with match rules (adapter, directory, label) that decide when a rule auto-attaches; memories are offered as suggestions and attached explicitly. For dispatched workers, a git-hosted context pack is fetched at boot and staged into the right place for the selected harness.
