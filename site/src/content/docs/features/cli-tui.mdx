## How it works

The terminal client is built on `cctui-clientcore`; the web UI keeps parity tests against the same readings (spend, attachments), so both clients show the same numbers. Admin screens, account editing and dispatch stay in the web UI; the TUI keeps the day-to-day loop. See the [command line reference](/cctui/reference/cli/).
