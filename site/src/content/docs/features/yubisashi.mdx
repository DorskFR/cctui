## How it works

Yubisashi is a mod installed from the plugin catalog. It uses the pane surface, the composer bridge and the daemon's preview proxy. The skill it ships tells the agent how to start the app behind the proxy so the pane can frame it; the pick resolves to source through the framework's dev-mode element metadata.
