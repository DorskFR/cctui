## How it works

The server runs a speech service for transcription and synthesis, configured under **Settings › Voice**. During a live voice session the gateway tees the agent's streamed text into the voice engine, so speech starts while the turn is still being written; playback state drives the voice UI. Dictation and voice notes use the same service through the normal REST routes.
