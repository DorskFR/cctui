## How it works

For Claude Code, the daemon registers a `PreToolUse` hook that blocks and long-polls the daemon for a decision; the daemon forwards the request to the server, which broadcasts a permission card to every client and replays it to late ones. Your answer travels back down the same path. Codex, opencode and ACP agents expose their own approval seams and are mapped onto the same card.

The gateway can apply a second, account-level guard: calls that match a tool policy are blocked on the wire, regardless of what the harness would have allowed, and the agent is told why.
